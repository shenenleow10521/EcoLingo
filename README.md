# EcoLingo

[Play EcoLingo on the web](https://ecolingo-pc-preview.leowshenen.chatgpt.site/)

EcoLingo is an interactive learning game about the UN Sustainable Development Goals. Complete lessons, quizzes, and eco-actions to grow your plant.

Sign in with Google or play as a guest using a nickname. Both modes share the weekly and all-time leaderboards.

See [deployment instructions](DEPLOY.md) for Supabase and Google sign-in setup.
